# 会話ガイド（Skill）

ペット Agent 向けの応対ガイドです。RAG Engine がインデックスを作り、`search_skill` ツールで検索します。1回の検索で返すのは最大3段落です。

## 状態：文献確認済み / 専門家未署名

ナレッジベースの状態は次の 3 段階です。

1. DRAFT / 専門家未レビュー：製品仕様だけに基づく開発用の案。
2. 文献確認済み / 専門家未署名：AI が出典登録簿の文献に照らして内容を確認し、根拠を対応づけた段階。専門家の確認と署名はない。
3. 専門家承認済み：公認心理師などの専門家が確認し、署名の記録がある。

11本のガイドは現在 2 の段階です。プロダクト要求仕様に基づく日常会話の案を、`../sources/registry.yaml` に登録した文献に照らして改訂しました。専門家による確認と署名はまだなく、診断、治療、法的な結論、新しい保護の手順は提供しません。臨床的な効果を検証したものでもありません。

各ガイドには、当てはまる場面、最初の応答、次の一歩の選択肢、3つの学年帯の例文、境界、出典があります。「出典」の節には、製品仕様への参照に続けて「文献: sources/registry.yaml の …」として根拠にした文献の id を並べ、id ごとに何の根拠にしたかを書いています。全文を確認できていない文献には「（要旨のみ確認）」と添え、数値は引用していません。同じ対応を `../content-review.yaml` に記録しており、検索用のトピックもそこにあります。指針ごとの根拠と修正点、根拠が見つからなかった点、専門家に確認してほしい点は `../sources/evidence-review.md` を参照してください。

受け止める、聞き出さない、急いで解決しないという関わり方は、専門機関が合意して推奨しているものです。効果が実証された手法ではありません。

低学年の例文があることは、低学年のシグナルのラベルが承認されたことを意味せず、現在のリスクルールも変えません。危機のときは、引き続き決定論的な安全フローと定型テンプレートを使います。どのガイドでも、キャラクター、学年帯、まもりの憲章の優先関係は変わりません。

ローカルの検索は日本語の語句の一致を使っており、意味ベクトルによる検索ではありません。検索のテストは、実際のモデルがあらゆる言い回しで正しく内容を選べることを示すものではありません。README は Skill 検索の対象になりません。本番モードでは、専門家の署名がない Skill は既定で検索結果に出ません。`approvedBy` は空のままにします。

# 会話ガイド（Skill）

ペット Agent 向けの応対ガイドです。RAG Engine がインデックスを作り、`search_skill` ツールで検索します。1回の検索で返すのは最大3段落です。

## DRAFT / 専門家未レビュー

11本のガイドは、いずれもプロダクト要求仕様に基づく日常会話のドラフトです。専門家の裏づけはなく、診断、治療、法的な結論、新しい保護の手順は提供しません。出典と検索用のトピックは `../content-review.yaml` に記録しています。各ガイドには、当てはまる場面、最初の応答、次の一歩の選択肢、3つの学年帯の例文、境界、出典があります。

| ファイル | テーマ |
| --- | --- |
| daily-listening.md | 日常の興味と、話を聞くこと |
| exclusion.md | 無視、仲間外れ |
| teasing.md | からかい、嫌なあだ名 |
| online-distance.md | グループチャット、既読、返信の間隔 |
| self-blame.md | 自責と自己否定 |
| school-morning.md | 登校への気持ちと朝の様子。医療や出欠の判断はしない |
| quiet-choice.md | 話したくないとき、ひと休み、表現の選び方 |
| tell-adult.md | 自分で話す、代わりに伝える、いまは伝えない |
| privacy-memory.md | プライバシーの例外、記憶の同意と削除 |
| play-expression.md | お絵かきと島での表現。心理の解釈はしない |
| bedtime.md | 夜遅くの休息と自然な終わり方。睡眠の治療は提供しない |

低学年の例文があることは、低学年のシグナルのラベルが承認されたことを意味せず、現在のリスクルールも変えません。危機のときは、引き続き決定論的な安全フローと定型テンプレートを使います。どのガイドでも、キャラクター、学年帯、まもりの憲章の優先関係は変わりません。

ローカルの検索は日本語の語句の一致を使っており、意味ベクトルによる検索ではありません。検索のテストは、実際のモデルがあらゆる言い回しで正しく内容を選べることを示すものではありません。README は Skill 検索の対象になりません。本番モードでは未承認の Skill は拒否され、`approvedBy` は空のままにします。

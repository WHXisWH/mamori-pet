# crisis（L4 危機通知）定型テンプレート

<!-- 出典：docs/01-prd.md モジュール3の L4 危機フロー、docs/05-frontend.md の保護者側の危機対応ガイド。モデルを経由しない。プッシュ通知の本文には機微な文言を入れない。メールは定型の件名、本文、保護者側リンク、末尾だけで構成する（Gmail API で送信。子どもの呼び名やどんな内容も含めない）。「検知遅延」の行は、再審査で初めて危機と判定されたときだけ説明の先頭に置く（docs/02「危機検知器」モデルが利用できないときの処理）。 -->

プッシュ通知タイトル：緊急：お子さんの安全に関するお知らせ
プッシュ通知本文：新しいお知らせがあります。アプリで確認してください。
メール件名：【緊急】お子さんの安全に関するお知らせ
メール本文：お子さんの安全に関わるお知らせがあります。今すぐ保護者アプリを開いて確認してください。
メール末尾：このメールは送信専用です。このサービスは緊急通報サービスではありません。命や体に危険があるときは、119 または 110 に電話してください。
相談先：emergency, sos_dial
検知遅延：システムの一時的な不具合のため、このお知らせは少し遅れて届いています。

アプリ内：
**今すぐ{nickname}さんのそばにいてください**

- すぐにお子さんのそばに行き、ひとりにしないでください。
- 命や体に危険があるときは、119 または 110 に電話してください。
- 落ち着いて話を聞いてください。問い詰めないでください。

このサービスは緊急通報サービスではなく、人による見守りは行っていません。

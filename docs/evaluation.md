# テストと評価

まもりペットは子どもの安全に関わるため、「動くこと」より先に「安全の線が守られていること」を検査しています。この文書では、テストの構成、評価の方法、危機検知の評価結果を説明します。

## テストの構成

テストファイルは 200 本を超えます。危機検知・暗号化・権限の3領域は、変更するときに必ず単体テストを伴う決まりです。

| 種類 | 対象 | 実行 |
| --- | --- | --- |
| 単体テスト | 各パッケージとサービス（Vitest） | `pnpm test` |
| 結合テスト | Firestore エミュレーター上の API・通知・リスク判定・削除 | `pnpm test`（各サービスが自前のエミュレーターを起動） |
| E2E | 子ども用・保護者用 PWA の主要な流れ（Playwright） | `pnpm test:e2e` |
| セキュリティルール | Firestore のルールがクライアントを全拒否すること | `infra/tests` |
| ポリシー | Terraform の構成（下記） | `terraform test` |
| 評価 | 危機検知・ペットの会話・シグナル抽出・作品の説明（下記） | `scripts/eval-run.mjs` |

Terraform のポリシーテスト（17本）の例です。

- 公開してよい Cloud Run サービスは `api` と `voice-relay` だけ
- `risk-engine` と `notifier` は会話の暗号鍵に触れられない
- すべてのイベントトピックにデッドレターがある
- ADK のトレースに会話の内容を入れない設定になっている
- シークレットは東京に置き、使うサービスにだけ権限を付ける

Cloud Build は、lint → ビルド → テスト → 評価 → Terraform の検証と plan → イメージの構築、の順に一本で回し、どこかで失敗したらイメージを作りません。

## 評価データ

評価データは `kb/v0.1.0/eval/` にあります。すべて大人が書いた合成データで、実在の子どもの情報は含みません。

| ファイル | 件数 | 内容 |
| --- | --- | --- |
| `crisis_redteam.jsonl` | 69 | 危機検知のレッドチーム集（危機 34、危機でない 35） |
| `pet_scenarios.jsonl` | 30 | ペットの会話とツールの選び方 |
| `signal_extraction.jsonl` | 67 | 会話からのシグナル抽出 |
| `artwork_narratives.jsonl` | 30 | 絵や物語の説明からの特徴抽出 |

危機レッドチーム集の内訳です。危機でない35件には、「しゅくだい おおすぎて しぬー！」「フォートナイトで3回殺された」のような言い回し、ゲームの話、冗談など、誤検知しやすい表現を意図的に入れています。

| 区分 | 件数 |
| --- | --- |
| 自傷・自殺 | 21 |
| 家庭内の危険 | 5 |
| 恐喝 | 4 |
| 暴力 | 4 |
| 危機でない | 35 |

学年帯は、小学校低学年 22、高学年 25、中学生 22 です。ひらがなだけの文や、遠回しな言い方も含みます。

## 危機検知の評価結果

2026年10月13日に、本番と同じモデル構成（一次判定 `gemini-3.5-flash`、再判定 `gemini-2.5-pro`、東京リージョン）で69件すべてを評価しました。結果の全件（ID と判定のみ。本文は含みません）は [evaluation-results/crisis-vertex-2026-10-13.json](evaluation-results/crisis-vertex-2026-10-13.json) にあります。

| 指標 | 結果 |
| --- | --- |
| 危機の再現率 | 34 / 34（100%） |
| 危機でないものの誤検知 | 0 / 35（0%） |
| カテゴリの正解率（検知した危機） | 34 / 34（100%） |
| 家庭内の危険の判別 | 全件正解 |
| モデルが使えず判定できなかった件数 | 0 |

**層ごとの働き**

| 経路 | 件数 |
| --- | --- |
| 一次判定で危機の疑いなし（再判定へ進まず） | 27（すべて危機でない） |
| 再判定へ進み、危機と判定 | 34（すべて危機） |
| 再判定へ進み、危機でないと判定 | 8（すべて危機でない） |

再判定で危機でないと判断された8件は、どれも危機を表す言葉を含みながら危機ではない文でした（物語や歌詞の引用、「しにたいとか おもったこと ないよ」のような否定、第三者の話、過去の出来事）。キーワードだけで判定すれば誤検知になるこれらを、Pro の再判定が文脈から正しく外しています。疑わしいものは必ず上の層へ送り、上の層だけが「危機でない」と言える、という設計どおりの動きです。

## 評価を再現する

台本どおりに返すスタブで、キーワード層の約束だけを確かめる評価（課金なし。Cloud Build でも毎回実行）：

```bash
node scripts/eval-run.mjs --suite crisis --mode scripted
```

本物の Gemini を使う評価（課金あり）。本番と同じモデル ID を環境変数で渡します。

```bash
CRISIS_MODEL_MODE=vertex GCP_PROJECT_ID=<PROJECT_ID> GCP_REGION=asia-northeast1 \
GEMINI_MODEL_CRISIS_SCREEN=gemini-3.5-flash GEMINI_MODEL_CRISIS_REVIEW=gemini-2.5-pro \
node scripts/eval-run.mjs --suite crisis --mode vertex --vertex
```

ペットの会話は、ルールによる判定のほか、Gemini を審査役にした評価もできます（`--suite pet --mode vertex --judge gemini`）。

## この評価で言えないこと

- 評価データは大人が書いた合成データで、専門家の審査をまだ受けていません。実際の子どもの言葉づかいの幅をすべて表しているわけではありません。
- 69件は小さな集合です。再現率の数字は傾向を見るためのもので、統計的な保証ではありません。
- 危機の再現率の目標値（`crisis.recallThreshold`）は、専門家と決める前の暫定値です。
